Unit 1 — The NetLogo world

An agent-based model represents a system through individual entities (agents), their attributes, the environment they occupy and the rules governing their interactions.

1. Four building blocks

  • turtles — mobile agents that can move around the world.
  • patches — the fixed square cells that make up the world.
  • links — connections between turtles.
  • observer — the global perspective that controls the model.

2. A first small model

This example creates 20 turtles at random positions. Each turtle is coloured blue.

to setup
  clear-all
  create-turtles 20 [
    set color blue
    setxy random-xcor random-ycor
  ]
  reset-ticks
end

3. What does the code do?

  • clear-all clears the previous model state.
  • create-turtles 20 creates 20 turtle agents.
  • set color blue sets each turtle's colour.
  • setxy places each turtle at a random x-y position.
  • reset-ticks resets the model's time counter.
Try it in the NetLogo desktop application: create a new model, paste the code, add a button linked to setup, and run it. This academy does not embed or execute NetLogo itself.

Applied modelling cases

These are teaching sketches to help connect ABM concepts to sustainability questions. They are not calibrated or validated research models.

Behaviour

Diffusion of sorting behaviour

Households are represented as agents. Their probability of adopting sorting may depend on exposure to neighbours who already sort. Explore how local influence and initial adoption shape collective outcomes.

Infrastructure

Access to biowaste collection

Households are placed in space and collection points are located on a grid. The exercise asks how distance to a collection point may affect sorting decisions. Real applications should consider road networks, capacity and service quality.

Prevention

Household food waste prevention

A planned case on household routines, food management practices, learning and the conditions that support waste prevention. The full lesson is under development.
